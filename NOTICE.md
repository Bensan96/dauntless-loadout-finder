# Notice

- **Game data** (perks, armor, weapons): collected by the Dauntless Builder Reforged project,
  https://github.com/atomicptr/dauntless-builder-reforged. Its README states: "The collected data itself is public domain."
  Only the data is used here. No source code from that project (AGPLv3) is included.
- **Crafting material refresh utility**: `scripts/build_materials.js` reads public item recipe tables from the Dauntless Wiki
  (https://dauntless.fandom.com/wiki/Dauntless_Wiki). No crafting quantities are currently bundled in this tool.
- **Game assets**: Dauntless and all related names and assets are the property of Phoenix Labs. This is an unofficial fan tool.
  The pictures in `assets/js/icons.js` are Phoenix Labs artwork, resized from the images in Dauntless Builder Reforged, and are
  used here for non-commercial fan purposes. If the rights holder asks, remove them and the tool still works without pictures.
- **Cell icons**: the six cell family symbols (Alacrity, Brutality, Finesse, Fortitude, Insight, Prismatic) are Phoenix Labs artwork from
  the same source, handled like the item pictures above.
